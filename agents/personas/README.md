# Persona blueprints

These Markdown files define optional roles, voices, beliefs, and review
perspectives. They are blueprints, not deployed agents.

The template's executable teaching example is `agents\outcome_framer.py`.
Implementing another persona requires separate code, tests, and an explicit
execution path.

## Use

1. Select the smallest role needed for a bounded task.
2. Treat the persona as perspective, not authority.
3. Keep customer-facing output professional and evidence-grounded.
4. Route real decisions through `needs-owner-input`.
5. Do not let a persona send, publish, deploy, or write externally without exact
   approval.
