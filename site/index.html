Agent teaching runtime

Portable operating model

MCAPS relationship, automation planes, review-and-go levels, and privacy boundaries.

Persona blueprints

Twelve optional perspectives organized into neighborhoods and quality guilds.

Synthetic demos

Contoso and Fabrikam examples that demonstrate outcome, evidence, review, and measurement.

Validation CI

Fails on private markers, real-looking environment URLs, malformed JSON, missing local links, or broken tests.

Start safely

Generate a private repository. Use the template button and keep the first experiment isolated.
Open the local sandbox. Run Start-Process .\web_ui\index.html.
Run the teaching agent. Use python .\scripts\run_agent.py "Your synthetic request".
Validate. Run python .\scripts\validate_template.py and the unit tests.
Add cloud resources only if needed. Dry-run setup first; registration remains separately opt-in.

Boundaries

Private stays private

No customer records, Microsoft 365 bodies, account strategy, credentials, environment IDs, or private repositories belong in the template.

Authority is explicit

Provisioning, pushing, deploying, registering, publishing, messaging, and operational writes each require their own approval.

Patterns cross the boundary

Share only reviewed, minimized patterns with provenance and validation evidence.
