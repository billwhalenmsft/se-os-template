# Shared discrete manufacturing context

## Portable concepts

- Asset, product, and installed-base relationships
- Work order, technician, skill, territory, and part relationships
- Warranty, return, quality, and service-case relationships
- Plant, supplier, distributor, and channel relationships

## Demo environments

No real environment is registered in this public template. A generated private
instance may add its own environment references in ignored local configuration.

## Seed data

Use Contoso Manufacturing, Fabrikam Service, and Northwind Distribution as
fictional examples.
