# Review and go

Automation intent is not authority. Use the lowest level that completes the
experiment.

| Level | Behavior | Example |
|---|---|---|
| L0 | Observe only | Inventory local template files |
| L1 | Draft or recommend | Prepare an outcome frame or deployment plan |
| L2 | Local, reversible action | Create or edit a branch-local artifact |
| L3 | External or durable write | Provision Azure, push, deploy, register, publish, or message |

## L3 requirements

Before an L3 action:

1. Show the exact destination and content or resource change.
2. Identify the identity and permissions being used.
3. Obtain explicit approval for that action.
4. Re-read the target state when possible.
5. Record a receipt or verifiable result.

Approval for one action does not authorize another. For example, approval to
deploy a Static Web App does not authorize workspace registration.
