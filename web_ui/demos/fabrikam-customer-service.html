Fabrikam customer-service demo pattern

Fictional organization and synthetic scenario

1. Ask

An agent needs a concise answer for a fictional product-return question.

2. Ground

The assistant uses only an approved synthetic article set and shows citations.

3. Review

The service agent checks the answer and supporting passages.

4. Respond

The agent chooses whether to use, edit, or discard the draft.

5. Measure

Track handling time, citation coverage, and correction rate.
