Experiment guide

  1. Generate a private repository.
  2. Open the local sandbox.
  3. Choose one bounded workflow and synthetic input.
  4. Run the local outcome-framing example.
  5. Validate privacy, links, JSON, and unit tests.
  6. Add connectors or cloud resources only after separate review.

Start at review-and-go level L0, L1, or L2. Do not connect a customer system merely to prove the sandbox works.
